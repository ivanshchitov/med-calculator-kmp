# МедКалькулятор

[🇺🇸 In English](README.md)

МедКалькулятор — это приложение на базе Kotlin Multiplatform для медицинских специалистов. Оно позволяет рассчитывать педиатрические дозировки лекарственных препаратов в зависимости от возраста и веса пациента. Работает на Android, iOS и в браузере как устанавливаемое PWA.

## Функциональность
- **Поиск препаратов**: Быстрый поиск и выбор из предустановленного списка лекарственных средств.
- **Расчет дозировки**: Расчет в миллиграммах (мг) и в миллилитрах (мл) на основе введенных параметров.
- **Контроль безопасности**: Проверка на превышение максимальной разовой дозы и соблюдение возрастных/весовых ограничений для каждого препарата.
- **Пути введения**: Поддержка различных способов введения (в/в, в/м, п/к) со специфичными правилами расчета для каждого.
- **Справочная информация**: Доступ к подробным сведениям о режимах дозирования и методах применения.
- **Офлайн-версия для веба**: PWA устанавливается на устройство и продолжает работать без подключения к сети после первой загрузки.
- **Обновления в приложении (Android)**: при запуске приложение проверяет новую версию в RuStore и предлагает неблокирующий баннер обновления с прогрессом загрузки.

## Источники данных
Режимы дозирования и алгоритмы расчета базируются на официальных данных следующих реестров:
- [Государственный реестр лекарственных средств (ГРЛС)](https://grls.minzdrav.gov.ru/).
- [Лекарственный справочник ГЭОТАР](https://www.lsgeotar.ru/).
- [Реестр ОХЛП и ЛВ ЕАЭС](https://lk.regmed.ru/Register/EAEU_SmPC).

## Поддерживаемые платформы
- Android 9+ (RuStore).
- iOS 18.2+.
- Web: современные браузеры с поддержкой WebAssembly. PWA устанавливается на главный экран и работает офлайн.

## Технологический стек
- **Kotlin Multiplatform (KMP)**: Общая бизнес-логика для Android, iOS и Web.
- **Compose Multiplatform**: Единый UI-фреймворк для создания нативных интерфейсов на мобильных платформах и в вебе.
- **Web-таргет**: Kotlin/Wasm и Compose Multiplatform for Web.
- **PWA**: service worker с генерируемым манифестом предзагрузки (`precache-manifest.json`) и офлайн-кешем для оболочки приложения, Wasm-модулей, шрифтов и данных о препаратах.
- **Аналитика**: MyTracker на Android и Web.
- **Обновления приложения**: RuStore In-app updates SDK и Compose-баннер на Android.
- **Архитектура**: Clean Architecture с использованием MVVM и модульной структуры по фичам.
- **Инъекции зависимостей (DI)**: Koin.
- **Хранение данных**: Room KMP на Android и iOS, DataStore с локальным хранилищем браузера на Web.
- **Асинхронное программирование**: Kotlin Coroutines & Flow.
- **Сериализация**: Kotlinx Serialization для работы с JSON.
- **Настройки**: DataStore Preferences.
- **Деплой**: AWS CLI и Yandex Cloud Object Storage.

## Структура проекта
- `:androidApp`: Модуль для сборки Android-приложения, включая контроллер и баннер обновлений RuStore.
- `iosApp`: Модуль для сборки для iOS-приложения.
- `:shared`: Основной модуль, содержащий общую логику и UI.
    - `commonMain`:
        - `composeResources`:
            - `drawable`: Общие векторные иконки.
            - `files`: Содержит `medications.json` — источник данных о препаратах.
            - `values`: Строки локализации (`strings.xml`).
        - `kotlin/org/dishch/medcalculator`:
            - `data`:
                - `local`: База данных Room KMP, DAO и определения сущностей (Entity).
                - `repository`: Реализации интерфейсов доменных репозиториев.
                - `PreferenceManager.kt`: Управление настройками на базе DataStore.
            - `di`: Модули Koin для инъекции зависимостей.
            - `domain`:
                - `model`: Чистые Kotlin-классы данных (Medication, CalculationResult, DosageRule).
                - `repository`: Абстрактные интерфейсы, определяющие операции с данными.
                - `usecase`: Основная бизнес-логика (например, расчеты, фильтрация препаратов).
            - `ui`:
                - `components`: Переиспользуемые UI-элементы (кастомные карточки, поля ввода, элементы списков).
                - `helpers`: Форматеры для UI и логика представления.
                - `screens`: UI-модули на основе фич (Главный экран, Выбор препарата, Результаты, О приложении).
                - `theme`: Реализация дизайн-системы Material 3 (Цвета, Типографика, Формы).
            - `AppNavigation.kt`: Граф навигации и определения маршрутов с использованием Compose Navigation.
            - `App.kt`: Корневой Composable-компонент приложения.
    - `androidMain`: Специфичные для Android реализации (драйвер БД, платформенные ресурсы, флоу обновления).
    - `iosMain`: Специфичные для iOS реализации и взаимодействие с нативным кодом.
    - `wasmJsMain`: Точка входа Web (`Main.kt`), `index.html`, `manifest.json`, `sw.js`, иконки PWA и конфигурация webpack dev-сервера.
    - `nonWebMain`: Слой данных, общий для Android и iOS (Room).
- `scripts/deploy_web.sh`: собирает веб-дистрибутив и загружает его в Object Storage.
- `.env.template`: шаблон конфигурации деплоя. Реальные секреты хранятся в `.env`, который исключен из git.

## Сборка и деплой веб-версии
Запуск dev-сервера:
```sh
./gradlew :shared:wasmJsBrowserDevelopmentRun
```

Сборка и загрузка production-PWA:
```sh
cp .env.template .env   # один раз, затем заполнить ключи доступа
./scripts/deploy_web.sh
```

Загрузка уже собранной версии без пересборки:
```sh
./scripts/deploy_web.sh --skip-build
```

Скрипт синхронизирует `shared/build/dist/wasmJs/productionExecutable` с бакетом с флагом `--delete`, ставит долгий кеш для хешированных ассетов, `no-cache` для `index.html`, `sw.js`, `precache-manifest.json` и `manifest.json`, а также принудительный `Content-Type: application/wasm` для `.wasm`.

Конфигурация (`.env`):
- `AWS_ACCESS_KEY_ID` — идентификатор статического ключа доступа Object Storage.
- `AWS_SECRET_ACCESS_KEY` — секрет статического ключа доступа Object Storage.
- `YC_S3_BUCKET` — имя бакета, `medcalculatorapp.ru`.
- `AWS_DEFAULT_REGION` — `ru-central1`.
- `YC_S3_ENDPOINT` — `https://storage.yandexcloud.net`.
- `PWA_PUBLIC_URL` — публичный URL, который печатается после успешного деплоя.

На бакете должны быть включены публичный доступ на чтение и хостинг статического сайта с `index.html` в качестве индексного документа. CDN не используется, поэтому шага инвалидации кеша нет.

## Примеры использования
1. **Экстренный расчет дозы**: Фельдшеру необходимо рассчитать дозу препарата для 5-летнего ребенка весом 20 кг. Он выбирает препарат, вводит параметры и мгновенно получает точный объем в мл для внутривенного введения.
2. **Проверка назначений**: Медсестра проверяет, не превышает ли назначенная доза максимальную разовую дозу, указанную в официальных инструкциях.
