# МедКалькулятор

[🇺🇸 In English](README.md)

МедКалькулятор — это мобильное приложение на базе Kotlin Multiplatform, разработанное для медицинских специалистов. Оно позволяет рассчитывать педиатрические дозировки лекарственных препаратов в зависимости от возраста и веса пациента.

## Функциональность
- **Поиск препаратов**: Быстрый поиск и выбор из предустановленного списка лекарственных средств.
- **Расчет дозировки**: Расчет в миллиграммах (мг) и в миллилитрах (мл) на основе введенных параметров.
- **Контроль безопасности**: Проверка на превышение максимальной разовой дозы и соблюдение возрастных/весовых ограничений для каждого препарата.
- **Пути введения**: Поддержка различных способов введения (в/в, в/м, п/к) со специфичными правилами расчета для каждого.
- **Справочная информация**: Доступ к подробным сведениям о режимах дозирования и методах применения.

## Источники данных
Режимы дозирования и алгоритмы расчета базируются на официальных данных следующих реестров:
- [Государственный реестр лекарственных средств (ГРЛС)](https://grls.minzdrav.gov.ru/).
- [Лекарственный справочник ГЭОТАР](https://www.lsgeotar.ru/).
- [Реестр ОХЛП и ЛВ ЕАЭС](https://lk.regmed.ru/Register/EAEU_SmPC).

## Поддерживаемые платформы
- Android 9+,
- iOS 18.2+.

## Технологический стек
- **Kotlin Multiplatform (KMP)**: Общая бизнес-логика для Android и iOS.
- **Compose Multiplatform**: Единый UI-фреймворк для создания нативных интерфейсов на обеих платформах.
- **Архитектура**: Clean Architecture с использованием MVVM и модульной структуры по фичам.
- **Инъекции зависимостей (DI)**: Koin.
- **Хранение данных**: Room KMP для локальной базы данных.
- **Асинхронное программирование**: Kotlin Coroutines & Flow.
- **Сериализация**: Kotlinx Serialization для работы с JSON.
- **Настройки**: DataStore Preferences.

## Структура проекта
- `:androidApp`: Модуль для сборки Android-приложения.
- `iosApp`: Модуль для сборки для iOS-приложения.
- `:shared`: Основной модуль, содержащий общую логику и UI.
    - `commonMain`:
        - `composeResources`:
            - `drawable`: Общие векторные иконки.
            - `files`: Содержит `medications.json` — источник данных о препаратах.
            - `values`: Строки локализации (`strings.xml`).
        - `kotlin/org.dishch.medcalculator`:
            - `data`:
                - `local`: База данных Room KMP, DAO и определения сущностей (Entity).
                - `repository`: Реализации интерфейсов доменных репозиториев.
                - `PreferenceManager.kt`: Управление настройками на базе DataStore.
            - `di`: Модули Koin для инъекции зависимостей.
            - `domain`:
              - `model`: Чистые Kotlin-классы данных (Medication, CalculationResult, DosageRule).
              - `repository`: Абстрактные интерфейсы, определяющие операции с данными.
              - `usecase`: Основная бизнес-логика (например, расчеты, фильтрация препаратов).
            - `ui`:
                - `components`: Переиспользуемые UI-элементы (кастомные карточки, поля ввода, элементы списков).
                - `helpers`: Форматеры для UI и логика представления.
                - `screens`: UI-модули на основе фич (Главный экран, Выбор препарата, Результаты, О приложении).
                - `theme`: Реализация дизайн-системы Material 3 (Цвета, Типографика, Формы).
            - `AppNavigation.kt`: Граф навигации и определения маршрутов с использованием Compose Navigation.
            - `App.kt`: Корневой Composable-компонент приложения.
    - `androidMain`: Специфичные для Android реализации (например, драйвер БД, платформенные ресурсы).
    - `iosMain`: Специфичные для iOS реализации и взаимодействие с нативным кодом.

## Примеры использования
1. **Экстренный расчет дозы**: Фельдшеру необходимо рассчитать дозу препарата для 5-летнего ребенка весом 20 кг. Он выбирает препарат, вводит параметры и мгновенно получает точный объем в мл для внутривенного введения.
2. **Проверка назначений**: Медсестра проверяет, не превышает ли назначенная доза максимальную разовую дозу, указанную в официальных инструкциях.
